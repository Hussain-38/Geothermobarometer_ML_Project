# AI-use record

AI assistance was used to help organize the research workflow, inspect workbook structure, draft analysis code, generate preliminary figures, and prepare proposal/presentation text.

Human verification required:
- confirm every geothermobarometer equation and output-slot identity against the primary calibration papers;
- inspect the original data sources and confirm experimental reference conditions;
- rerun the final XGBoost and SHAP workflow independently;
- review all numerical results, interpretations, limitations and citations;
- approve any data sharing and repository publication.

AI-generated interpretations are not treated as independent scientific validation.
